title: 設計判断
description: Architecture Decision Record の索引。
---

実装と文書を同じ契約に対してレビューできるよう、長期的な判断を ADR に記録します。

製品範囲、単一 package とモジュール境界、同期実行、コンテナ/意味パイプライン分離、点群所有権、厳密なプランニング、出力忠実性、Linux 対応、文書、配布、フォーマット依存、テストを扱っています。

[ADR 一覧](https://github.com/takeshiD/pcx/tree/main/docs/adr)を参照してください。置き換えられた判断も履歴として保持し、後継 ADR へリンクします。
