title: Design decisions
description: Architectural decision record index.
---

Durable choices are recorded as ADRs so implementation and documentation can be reviewed against the same contracts.

The records cover product scope, the one-package module topology, synchronous execution, the split container/semantic pipelines, point ownership, strict planning, output fidelity, Linux support, documentation, distribution, format dependencies and testing.

Read the [ADR index](https://github.com/takeshiD/pcx/tree/main/docs/adr). A superseded record is retained as history and links to its replacement.
