# JSON compatibility goldens

These reviewed fixtures are generated by the compiled `pcx` process from the
checked-in format corpus. `info.json` and `topics.json` use
`tests/fixtures/valid/pointcloud2.mcap`. Error fixtures use
`tests/fixtures/malformed/mcap-leading-magic-must-match.mcap`.

`<normalized-message>` replaces diagnostic wording because the error category
is stable while message text is deliberately non-contractual. No sensor data,
credentials, or device identifiers are present. CI compares output but never
updates these files.
