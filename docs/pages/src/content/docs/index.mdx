`pcx` helps robotics and LiDAR engineers understand a recording before moving gigabytes off a robot. It is designed as a single synchronous executable with bounded managed memory and a binary-safe stdout.

<ul class="status-list">
  <li class="status-card" data-state="available"><strong>Available</strong><span>MCAP metadata inspection, help/version, architecture, tests, Nix and delivery foundation.</span></li>
  <li class="status-card" data-state="planned"><strong>Planned for v0.1</strong><span>Topic listing and one ROS 2 PointCloud2 frame to PCD.</span></li>
  <li class="status-card" data-state="out"><strong>Out of scope</strong><span>AWS/S3 clients, cloud credentials, daemon mode, GUI and ROS runtime.</span></li>
</ul>

## One workflow

```text
inspect -> reduce -> transfer with existing shell tools
```

```bash
# `info` is available; the remaining commands are planned.
pcx info run.mcap
pcx topics run.mcap --json
pcx extract run.mcap --topic /lidar/points --frame 0 -o frame.pcd
```

The project is explicit about what exists today. Planned examples are labeled so that documentation never masquerades as implementation.
